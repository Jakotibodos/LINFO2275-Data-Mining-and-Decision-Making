\section*{Introduction}
In this project, we present the implementation of a Markov Decision Process to solve a Snakes and Ladders game. To do so, we implemented the value iteration algorithm to find the optimal policy for the game. This policy specifies, for each tile, the best dice to use in order to minimize the expected number of turns to reach the goal (tile 15). Afterwards, we compared this optimal policy to other suboptimal policies, such as fixed-dice policies, to see how they perform in terms of expected number of turns to win the game. Both theoretical results from value iteration and empirical results from Monte Carlo simulations are analyzed, presented and compared across different trap layouts, for both game configurations.

%\noindent To compare our theoretical results from value iteration with empirical results, we used Monte Carlo simulations. We simulated a large number of games using the optimal policy and computed the average number of turns to win the game, which should be close to the expected number of turns computed by value iteration. We also compared the optimal policy with sub-optimal policies by simulating games using those policies and computing their average number of turns to win the game.


\section*{Theoretical background}

The game is modeled as a Markov Decision Process. As seen during the lectures, it is defined by 
\begin{itemize}
    \item a set of states $S$, which in our case corresponds to the tiles of the board, i.e. $S = \{1, 2, \dots, 15\}$;
    \item a set of actions $A$, which corresponds to the choice of dice to roll, i.e. $A = \{1, 2, 3, 4\}$;
    \item a transition function $P(s' \mid s, a)$, which gives the probability of reaching state $s'$ from state $s$ after choosing action $a$. These probabilities are determined by the stochastic outcomes of the dice, the branching structure of the board, and the activation of traps;
    \item a cost function $c(s \mid a)$, which gives the cost when taking action $a$ in state $s$. In our case, we can define the cost as 1 for each turn taken, and 0 for reaching the goal (tile 15).
\end{itemize}

\noindent The goal is to find an optimal policy $\pi^*$ which specifies the best dice to use at each tile in order to minimize the expected number of turns to reach tile 15 from any initial state. Let $V(s)$ be this total expected number of turns which respects Bellman's equation with as condition $V(15)=0$:
\begin{equation}
    V(s) = \min_{a \in A} \left[ c(s \mid a) + \sum_{s' \in S} P(s' \mid s, a) V(s') \right]
\end{equation}


\noindent This optimal expected number of turns can be computed using the value iteration algorithm, which iteratively updates $V(s)$ for each state until convergence. The optimal policy is then obtained by selecting, for each state, the action that minimizes the Bellman equation. \\

\noindent To validate the theoretical results, we performed Monte Carlo simulations. To do so, we simulated 1000 games from the initial state until the goal state following a policy, and we computed the empirical average number of turns. We also computed the standard deviation of these estimates. These are then compared to the theoretical values obtained through value iteration in order to validate the correctness of the optimal policy.

\section*{Implementation description}

\subsection*{Trap layouts}

We chose to use 6 different trap layouts to compare the optimal policy in different settings. These layouts are the following :
\begin{itemize}
    \item \textbf{No traps}: this layout has no traps, which means that the player can only move forward and never go back. This is the simplest layout and serves as a baseline for comparison.
    \item \textbf{Few traps}: this layout has a few traps scattered throughout the board.
    \item \textbf{Many traps}: this layout has many traps scattered throughout the board, which makes it more difficult to win the game.
    \item \textbf{Evil fast lane}: this layout has traps only on the fast lane.
    \item \textbf{Two-in-a-row traps}: this layout has two-times two traps in a row, which makes it more difficult to avoid them.
    \item \textbf{Back-to-three traps}: this layout has traps that send the player back to tile 3, which is the branching tile.

\end{itemize}

\subsection*{Sub-optimal strategies}
\noindent We chose to implement five sub-optimal strategies to compare with the optimal policy. These strategies are the following :
\begin{itemize}

    \item \textbf{One dice only}: for each of the 4 dices, we made a policy that always chooses that dice. This gives us 4 sub-optimal policies to compare with the optimal one.
    \item \textbf{Uniform random strategy}: this policy chooses a dice uniformly at random, independently of the current tile. This is a baseline strategy.

\end{itemize}
