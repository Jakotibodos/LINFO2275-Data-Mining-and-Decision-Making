\section*{Introduction}
In this project, we present the implementation of a Markov Decision Process to solve a Snakes and Ladders game. To do so, we implemented the value iteration algorithm to find the optimal policy for the game. This policy specifies, for each tile, the best dice to use in order to minimize the expected number of turns to reach the goal (tile 15). Indeed, the player may choose between four different dices at each turn, each with some probabilities of moves and traps triggering. There are two game configurations considered: one circular (must stop on tile \texttt{15} exactly) and a linear (must only reach tile \texttt{15}). Afterwards, we compared this optimal policy to other suboptimal policies, such as fixed-dice policies, to see how they perform in terms of expected number of turns to win the game. Both theoretical results from value iteration and empirical results from Monte Carlo simulations are analyzed, presented and compared across different trap layouts, for both game configurations.

%\noindent To compare our theoretical results from value iteration with empirical results, we used Monte Carlo simulations. We simulated a large number of games using the optimal policy and computed the average number of turns to win the game, which should be close to the expected number of turns computed by value iteration. We also compared the optimal policy with sub-optimal policies by simulating games using those policies and computing their average number of turns to win the game.


\section*{Theoretical background}

The game is modeled as a Markov Decision Process. As seen during the lectures, it is defined by 
\begin{itemize}
    \item a finite set of states $S$, which in our case corresponds to the tiles of the board, i.e. $S = \{1, 2, \dots, 15\}$;
    \item a set of actions $A$, which corresponds to the choice of dice to roll, i.e. $A = \{1, 2, 3, 4\}$;
    \item a transition function $P(s' \mid s, a)$, which gives the probability of reaching state $s'$ from state $s$ after choosing action $a$. These probabilities are determined by the stochastic outcomes of the dice, the branching structure of the board, and the activation of traps;
    \item a cost function $c(s \mid a)$, which gives the cost when taking action $a$ in state $s$. In our case, we can define the cost as 1 for each turn taken, and 0 when reaching the goal (tile \texttt{15}).
\end{itemize}

\noindent The goal is to find an optimal policy $\pi^*$ specifying, at each tile, which dice minimizes the expected number of turns to reach tile \texttt{15} from any initial state. Let $V(s)$ be this total expected number of turns which respects Bellman's equation with as condition $V(15)=0$:
\begin{equation}
    V(s) = \min_{a \in A} \left[ c(s \mid a) + \sum_{s' \in S} P(s' \mid s, a) V(s') \right]
\end{equation}


\noindent This optimal expected number of turns can be computed using the value iteration algorithm, which iteratively updates $V(s)$ for each state until convergence. The optimal policy is then obtained by selecting, for each state, the action that minimizes the Bellman equation. \\

\noindent To validate the theoretical results, we performed Monte Carlo simulations. To do so, we simulated \texttt{1000} games from the initial state until the goal state following a strategy, and we computed the empirical average number of turns, $\bar{T}$. We also computed the standard error of these estimates based on the sample standard deviation $\hat{\sigma}$.
\begin{equation*}
    \begin{split}
        \bar{T} &= \frac{1}{N} \sum_{i=1}^{N} T_i \\
        \mathrm{SE} &= \frac{\hat{\sigma}}{\sqrt{N}}
    \end{split}
\end{equation*}
$\bar{T}$ is then compared to the theoretical value $V(1)$ obtained through value iteration in order to validate the correctness of the optimal policy.

\section*{Implementation description}

\subsection*{Trap layouts}

We chose to use 6 different trap layouts to compare the optimal policy in different settings. These layouts are the following :
\begin{itemize}
    \item \textbf{No traps}: this layout has no traps, which means that the player can only move forward and never go back. This is the simplest layout and serves as a baseline for comparison.
    \item \textbf{Few traps}: this layout has a few traps teleporting the player three squares backward scattered throughout the board.
    \item \textbf{Many traps}: this layout has many traps of all types scattered throughout the board, which makes it more difficult to win the game.
    \item \textbf{Evil fast lane}: this layout has restart and backward traps only on the fast lane.
    \item \textbf{Two-in-a-row traps}: this layout presents two segments with two consecutive backward trap tiles, making it more difficult to avoid them.
    \item \textbf{Back-to-three traps}: this layout has traps that send the player back to tile \texttt{3}, which is the branching tile.

\end{itemize}

\subsection*{Sub-optimal strategies}
\noindent We chose to implement five sub-optimal strategies to compare with the optimal policy. These strategies are the following :
\begin{itemize}

    \item \textbf{One dice only}: for each of the 4 dices, this policy simply chooses one specific dice. This gives us 4 sub-optimal policies to compare with the optimal one.
    \item \textbf{Uniform random strategy}: this policy chooses a dice uniformly at random, independently of the current tile. This is a baseline strategy.

\end{itemize}

\subsection*{Optimal Policy}
For each trap layout defined above, we represented the game and the optimal policy by coloring the tiles according to the dice that should be used on that tile. The shape of the tile indicates which type of trap is present on it (if any), and the number in them indicates the theoretical expected number of turns to win the game from that tile when following the optimal policy. For each trap layout, we represented both the circular and linear game structures, to see how the optimal policy changes when the layout loops or not.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.99\linewidth]{mdp_outputs/no_trap_layout.pdf}
    \caption{Expected number of turns to win the game from each tile for the no traps layout. The tile color represents the optimal policy obtained through value iteration. }
    \label{fig:no_trap_layout}
\end{figure}

\noindent\autoref{fig:no_trap_layout} shows the optimal policy in the case where no traps are present, in both the circular and linear game structures. For tiles closer to the goal, the circle structure favors safer dice as we must stop exactly on the goal, while the linear structure favors faster dices as we can overshoot the goal. 
Indeed, since moving back to tile \texttt{1} is always a bad outcome, which is the case in overshoot, the optimal policy will always choose dice \texttt{1} (the safe dice) on both possible last tiles when the layout is circular, regardless of the trap layout. 
For the rest of the tiles, the policy mostly favors dice \texttt{3}, as it has the highest expected value (\texttt{1.5}) of displacement of all dice, when traps are not triggered. This confirms that, when no penalties are present, the best strategy is to take as much risk as possible to get to the goal faster. Dice \texttt{4} (the special dice) is chosen on tile \texttt{1}, since the player cannot move further back, bringing the expected value of the dice to \texttt{2}. Tiles \texttt{4} and \texttt{6} also favor the special dice, since there is a 1/4 chance to move back directly to tile \texttt{3} and potentially move to the fast lane. 
We find it surprising that tile \texttt{3} itself does not favor the special dice, as it could directly land on the goal tile.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.99\linewidth]{mdp_outputs/few_traps_layout.pdf}
    \caption{Expected number of turns to win the game from each tile for the few traps layout.}
    \label{fig:few_traps_layout}
\end{figure}

\noindent \autoref{fig:few_traps_layout} adds a few penalty traps into the layout. We see some recurring patterns like choosing safer dices close to the goal for the looped layout and prioritizing the riskier dices in safer regions.
On most trapped tiles, the optimal policy chooses the risky dice even with the $\frac{1}{4}$ chance of activating the trap.
This can be explained by comparing the expected displacement: even with the penalty traps which effectively act as -3 rolls when starting on them, the risky dice has an expected value of $\frac{3}{4}$, which is higher than the safe and normal dices ($\frac{1}{2}$). 
More interestingly, the optimal policy clearly tries to avoid the traps when it can by anticipating them. For example, it chooses the normal dice on tile \texttt{4} to get closer to the trapped tile \texttt{7} until it is close enough (on tile \texttt{5} or \texttt{6}) to be able to leap over the trap using the special dice.

The non-looped layout prioritizes heavily taking the fast lane, as seen by the choice of the safe dice on tile \texttt{2}. Even if taking the fast lane is not guaranteed, if there is even a slight chance of going there, it takes it.
In practice, the player will only rarely take the fast lane with this policy since the only way to end on tile \texttt{2} is to roll a -3 when standing on tile \texttt{5}. Still, when it happens, it is a huge speedup.

As see in \autoref{fig:many_traps_layout}, having many traps unsurprisingly leads to the near exclusive use of the safe dice.
As the safe dice moves the player by at most \texttt{1} tile, having the layout loop or not doesn't affect the optimal policy choice or its effectiveness. 
This is further shown by comparing to the only dice \texttt{1} strategy, which takes almost the same number of turns as the optimal strategy.

\noindent When designing the \textit{evil fast lane} layout seen in \autoref{fig:evil_fast_lane_layout}, we expected the optimal policy to avoid the fast lane at all costs. However, that is not what we observe, as the choice of the special dice at tile \texttt{7} for the looped layout and tile \texttt{4} for the non-looped layout may directly lead the player to land on tile \texttt{3} and merge into the fast lane.
This is an acceptable outcome for the model, since rolling a \texttt{5} with the special dice from tile \texttt{3} would lead directly to the goal tile when taking the fast lane.

In the layout shown in \autoref{fig:two_in_a_row_traps_layout}, we observe a drastic difference in strategy between the looped and unlooped boards. In the looped board, the player tries to leap the traps, but only from tiles that guarantee it can land on or before the goal if it rolls a \texttt{5}, as shown by the choice of the special dice on tiles \texttt{5} and \texttt{6}. However, in the unlooped layout, the player prefers inching closer using the normal dice, even risking the activation of the trap on tiles \texttt{8}, \texttt{13} and \texttt{14}, so that a \texttt{3} or a \texttt{5} on the special dice makes it reach the goal (skipping over the 2 traps in a row).

In the back-to-3 layout shown in \autoref{fig:back_to_three_layout}, the optimal strategy becomes much more sophisticated. In the looped layout, the player would much rather take the fast lane (as evidenced by the choice of the safe dice on tile \texttt{2}) since it avoids having to tiptoe past the restart trap on tile \texttt{10}.
Surprisingly, the optimal strategy chooses the risky dice at tile \texttt{8}, risking triggering the restart trap. It appears that the risk of restarting is worth taking over moving slowly (with the safe dice) to the goal.
The player in the non-looped layout does not benefit as much from the fast lane, as it can simply leap over tile \texttt{10} to reach the goal with the special dice.

\subsection*{Theoretical vs Empirical Results: Sub-optimal Strategies}
We compared the optimal policy with the 5 sub-optimal strategies by simulating \texttt{1000} games for each policy and game structure (circle or not) with Monte Carlo simulations. We also included the theoretical expected number of turns, $V(1)$, for each strategy computed by value iteration. In all experiments, empirical means are very close to the theoretical values, indicating the convergence of the value iteration algorithm. Note that, for some layouts that are not shown in this report, no convergence could be achieved for any strategy (including the optimal one), as the player would get stuck in traps and never reach the goal. This, for example, could happen when restart and penalty traps are present on the four first tiles, as the player will always get teleported back to the start of the board and never reach the goal, leading to an infinite expected number of turns.

\section*{Conclusion}
% GAVIN
Overall, value-iteration consistently provides the least number of turns compared to other more naive strategies. 
It accomplishes this with, at least for this relatively small problem, usually below 50 iterations. In problems with simple models such as this one, a tighter stability tolerance is reasonable given the fast per-iteration calculation time.
For problems with a high cost per iteration, either computationally or monetarily, a larger stability tolerance could be chosen. 
By selecting a larger stability tolerance, the number of iterations can be decreased in exchange of a suboptimal but quicker to determine policy. 
This makes value-iteration a flexible tool for dealing with MDPs of all problem sizes. 
Another factor to consider is problem complexity. For simple cases such as "many-traps" the naive solution performs comparably to the optimal strategy, with no value-iteration step required.

%Lore
Overall, the optimal policy obtained through value iteration consistently outperformed the sub-optimal strategies across all trap layouts and game configurations. The advantage of the optimal policy was particularly significant because of the heterogeneous way to use dices, as using riskier dices in the beginning and safer ones later. The Monte Carlo simulations validated the theoretical results, as the empirical average number of turns closely matched the expected number of turns computed by value iteration for all strategies and layouts. This confirms the correctness of our implementation and the effectiveness of the optimal policy in minimizing the expected number of turns to win the game.
